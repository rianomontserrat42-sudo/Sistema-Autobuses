# Sistema de Autobuses

Aplicación web para la venta de boletos de autobús de Roteiros do Sul Turismo.

## Características

- Mapa de 30 asientos
- Venta de boletos
- Listado de boletos vendidos

## Tecnologías

- Python

## Estructura del proyecto

- `pagina.py`: interfaz web
- `basedatos.py`: manejo de datos
- `validaciones.py`: validación de datos

## Cómo ejecutarlo

1. Clona el repositorio
2. Instala las dependencias
3. Ejecuta `python pagina.py`
